# Progress

Resume file for the reading workflow. Read this first after a context reset.

## Workflow
1. **Structure first.** Fetch the table of contents and chapter list before reading anything.
2. **Pass 1, per chapter.** Read each chapter in full (in chunks of about 45,000 characters), take notes in my own words, view every figure. Output: raw notes, then `docs/chapters/<book>/chapter-NN-summary.md`.
3. **Pass 2, synthesis.** Build the cross-book artifacts from the chapter summaries: `executive-summary.md`, `knowledge-map.md`, `requirements.md`, `claims.md`.
4. **Pass 3, use.** Turn the material into course lessons, POCs and interview drills.
5. **Record state here** after each step.

## Rebuild
```bash
python course/build.py                          # course/index.html
python course/synthesis.py                      # executive summary, map, requirements
python tools/build_reading_docs.py course/index.html   # chapter summaries + claims (also reruns synthesis)
make test && make validate
```
Synthesis content lives in `course/synthesis.py` (one source for both the docs and the course pages). Platform lessons live in `course/pe*.py`; SRE lesson furniture in `course/extras*.py`.
